# 🎓 Neosis

## Overview

**Neosis** is an AI-powered web application that enhances the learning experience through personalized educational content. 
By leveraging artificial intelligence, the platform generates customized courses, quizzes, and study materials tailored to each 
learner's knowledge level and learning objectives. The goal of Eduto is to provide an adaptive and interactive 
learning environment that helps students study more efficiently and improve knowledge retention.

---

## ✨ Features

### 📚 AI-Generated Courses

Generate personalized learning paths based on the user's interests, experience level, and educational goals. Each course is organized into structured lessons with clear learning objectives to support progressive learning.

### 📝 AI-Generated Quizzes

Automatically create quizzes from course content to evaluate understanding and reinforce learning. The platform supports various question formats, including:

* Multiple-choice questions
* Short-answer questions
* Concept-based assessments

Instant feedback helps learners identify areas for improvement.

### 🎯 Personalized Learning Experience

Eduto adapts to each learner's progress by analyzing performance and generating content that matches their needs. The system reinforces weaker topics while introducing more advanced material as the learner improves.

### 🗂️ AI-Powered Flashcards

Generate flashcards from learning materials to facilitate active recall and spaced repetition. This feature helps students review key concepts efficiently and improve long-term retention.

## 📌 Project Vision

Eduto aims to make learning more accessible, engaging, and personalized by integrating artificial intelligence into educational workflows. Through adaptive content generation and intelligent assessment, the platform empowers learners to study more effectively and achieve their educational goals.
